# Spotify Social Media Performance Analysis

## Project Overview

This project analyzes Spotify's social media performance across multiple platforms using Microsoft Excel.

The project includes data cleaning, engagement analysis, platform comparison, hashtag analysis, campaign performance evaluation, follower growth tracking, retention analysis, and correlation analysis.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Data Cleaning Techniques
* Statistical Analysis

## Dataset

The dataset contains:

* Social media posts
* Campaign metadata
* Engagement metrics
* Follower statistics
* Hashtag information

## Project Workflow

1. Data Cleaning
2. Hashtag Expansion
3. Engagement Analysis
4. Platform Performance Analysis
5. Hashtag Performance Analysis
6. Campaign ROI Analysis
7. Follower Growth Analysis
8. Follower Retention Analysis
9. Correlation Analysis

## Key Findings

* ChillVibes campaign achieved the highest ROI.
* Platform performance varied significantly across content types.
* Hashtag effectiveness influenced engagement rates.
* Follower growth and retention metrics provided audience insights.
* Correlation analysis highlighted relationships among engagement metrics.
